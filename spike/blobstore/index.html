THROWAWAY — spike/ is disposable harness, not app code

Hashigo blob store — 624.6 MiB of real mp3 as BLOB rows in OPFS

Runs SqliteBlobStore from src/blobs/sqlite.ts — the same class test/blobs.test.ts runs in Node — over opfs-sahpool in a dedicated Worker. It writes the whole real corpus, rehashes every payload with src/blobs/sha256.ts, and audits the payload store against the real card database. The main thread holds no database handle and no store.
