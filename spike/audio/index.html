THROWAWAY — spike/audio/ is disposable harness, not app code

A real mp3 from the corpus, out of a SQLite blob store in OPFS, decoded by a real browser

The worker owns both databases: a card-shaped blobs table with no payloads and no locations, and a SqliteBlobStore holding the real Azure TTS mp3s as BLOB rows. Bytes reach this page by transfer and become playable through src/blobs/url.ts — the only production file on trial here. A clip counts as proven when its duration is finite, its clock advances and its events fire, not when an element merely has a src.
