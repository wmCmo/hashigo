# Counter

Cards left today, top-right: the live dot (`accent` with `shadow-dot`), the count in `counter` type in `ink-strong`, and `/total` in `counter-total` type in `ink-2` under its right edge.

**You provide** `value`, optionally `total`, and `idle` when the session is done or paused (the dot goes `ink-3`).

- Count down what is left, not up what is done.
- The dot is the screen's second and last ruri; do not add a third.
