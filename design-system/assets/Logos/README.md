# Logos

- `mark.svg`: the full mark, three rungs plus the loose top rung. Rails and rungs are `ink` (#3A3A3A); the top rung is `accent` (#1F5FE0). Use at 24px and up.
- `favicon.svg`: the small two-rung construction, in the same two inks. Use under 24px.

Both are fixed light-theme colours, because `<img>` cannot inherit a colour. On a dark ground, draw the mark inline with `ink` and `accent` instead.
