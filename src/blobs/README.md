# src/blobs — the store that owns the bytes. Content-addressed by sha256, refcounted by the schema, and deliberately holding NO location: the database stores `blobs.hash`, the payload lives at `<root>/<shard>/<hash>`, and the root is a runtime argument. Move, rename or re-mount the store and every reference still resolves — `src/blobs/cli.ts --store <elsewhere> verify` is how you check. `address.ts` and `store.ts` are pure (the OPFS build imports those); `node.ts` is the filesystem implementation; `db.ts` audits, resolves and sweeps.
